01 / CAPABILITIES

把「传文件」做成一次对话

不是网盘，不是云同步，不是远程桌面 —— 是同一间办公室里，两台电脑之间的直连通道。

01

零配置设备发现

UDP 组播 + 定向广播双通道心跳，3 秒一轮自动发现同网段设备；多网卡环境自动遍历全部物理网卡，15 秒无心跳即标记离线。

02

配对式可信连接

双方生成 6 位人工校验码，肉眼核对即可确认未被中间人篡改；必须由接收方点击接受，120 秒未处理自动拒绝。

03

端到端加密

X25519 长期身份密钥 + ECDH 派生共享密钥，HKDF-SHA256 派生会话密钥，消息与文件分块以 ChaCha20-Poly1305 加密并带认证标签。

04

微信式即时沟通

文字、表情、图片、语音、文件卡片统一进入消息流；两分钟内可撤回并留痕，支持多选转发与合并转发，聊天记录可整体清理。

05

大文件断点续传

默认 4 MiB 分块逐块加密上传，接收端以文件摘要为键持久化已收分块；传输中断后可跨会话续传，完成时流式 SHA-256 校验通过才落盘。

06

随时隐身与可控可见

设置中关闭「允许被扫描发现」即停止广播心跳，进入隐身模式；对方仍可通过 IP + 端口手动添加，在线状态由 HTTP 探活独立判定。

02 / PROTOCOL

四步，建立一条私有链路

没有中心服务器参与协调，所有协商都发生在两台机器之间。

  1. STEP 01

    发现

    广播心跳，自动识别 Windows / macOS / Linux 节点并展示在线状态与局域网 IP。

  2. STEP 02

    配对

    接收方确认并核对 6 位校验码，双方建立长期信任关系，未配对节点无法发起任何请求。

  3. STEP 03

    握手

    ECDH 交换密钥，HKDF-SHA256 派生会话密钥，全程在本机完成，不经第三方。

  4. STEP 04

    直连

    分块加密上传、实时进度、断点续传；消息与文件直接在两台设备间流动。

03 / SECURITY

文件与消息内容，
不会离开这条链路

澜链的核心假设很简单：同一间办公室里的两台电脑，不应该为了互传一个文件而把内容交给某个中心节点。

  • 私钥不出本机X25519 长期密钥对在首次启动时生成，私钥仅存本机配置目录，不随安装包分发。
  • 未配对即无权接口层拒绝未授权节点的每一次消息与传输请求，配对必须由接收方主动确认。
  • 落盘前必校验文件内容经流式 SHA-256 比对摘要，校验通过才写入存储目录，避免损坏文件落盘。
  • 离线也完整可用除版本检查外全部功能在本地完成，断网环境下依然可以互传与聊天。

06 / FAQ

常见疑问

安装后还需要注册或登录账号吗？

不需要。澜链没有任何账号体系，打开即可使用；设备之间的信任通过配对时的 6 位校验码建立，卸载重装后重新配对即可。

必须联网才能使用吗？

不需要。除启动后后台异步检查版本更新外，设备发现、配对、传输与聊天全部在本地网络内完成，断网环境同样可用。

支持 Linux 吗？

仓库内已包含 Linux 构建配置，可自行构建 .AppImage 与 .deb；本页面目前提供官方维护的 Windows 与 macOS 安装包。

收到的不明文件会被自动运行吗？

不会。可选的「接收后自动打开」仅对图片、文档、音视频等安全预览类型生效，exe、bat、ps1、msi、vbs、docm 等可执行或脚本文件一律不自动运行。

收到的文件存在哪里？可以自己指定吗？

默认落在 LanLinkData/ 下的 files / images / voice 目录，按日期分层存放；可在设置面板改到其他磁盘，跨磁盘落盘会自动改用复制策略。

支持多人群发吗？

支持多选已配对在线设备进行群发：文字、表情、图片与文件均可，任务中心按设备展示进度与结果，并支持取消剩余目标与重试失败目标。群聊暂不在当前版本范围内。
